# 월간 방송 스케줄

스트리머 한 명이 방송 화면에서 직접 월간 일정을 작성하고 관리하는 GitHub Pages용 단일 페이지 웹앱입니다.

## 주요 기능

- 월간 달력과 날짜별 일정 표시
- 방송, 휴방, 합방·CK, 대회·경기, 이벤트 분류
- 매주·매월 반복 일정
- 대한민국 공휴일 표시(2025~2027)
- 일정 추가·수정·삭제와 상세 보기
- 브라우저 자동 저장
- JSON 백업과 복원
- 달력 집중 보기
- 모바일·태블릿·PC 반응형 화면

## 저장 방식

일정은 웹사이트를 연 브라우저의 `localStorage`에 저장됩니다. 다른 기기나 다른 브라우저와 자동 동기화되지는 않으므로 중요한 일정은 상단의 **백업** 버튼으로 파일을 보관하세요.

## GitHub Pages

저장소의 `main` 브랜치 루트를 GitHub Pages로 지정하면 `index.html`이 바로 배포됩니다.
